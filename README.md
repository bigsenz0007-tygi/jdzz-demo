# 京东直招 · 交互预览

基于 Figma `wuc0KiBBdjMbbl0XMEOdF9` 制作的 375px 移动端高保真交互预览。
项目使用原始高清切图、SVG 图标和少量动态 HTML，以支持职位筛选、列表与详情字段联动、报名等演示流程。

## 启动

端口 **4192**（不占用其他预览）：

```bash
cd "/Users/zhouxingzi1/Desktop/text/【1012-京东直招】"
python3 -m http.server 4192 --bind 127.0.0.1
```

浏览器打开：<http://127.0.0.1:4192/>
